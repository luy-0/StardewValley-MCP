# Mod 能力清单

当前公开 V1 已实现 **22 项能力**：6 项只读观察能力、16 项游戏操作能力。

本页只展示实现状态，不重复定义协议。详细行为见 [`spec/capabilities/behavior.md`](../spec/capabilities/behavior.md)，权威能力集合见 [`spec/capabilities/manifest.yaml`](../spec/capabilities/manifest.yaml)。

状态说明：✅ 已实现并注册；🧩 已实现为可执行 Skill；🟡 已列入后续候选；⚪ 由 Agent/Skill 指引编排，不计划增加 Mod 复合命令。

## Agent/Skill 编排

下列目标由现有原子能力组合完成，不计划在 Mod 中增加批处理或复合 Handler：

| 工作流 | 状态 | 组合方式 |
|---|---:|---|
| 重复使用工具直到目标消失 | ⚪ | `query_world → use_tool → query_world` 有界循环 |
| 抚摸动物、拾取掉落物、区域采矿 | ⚪ | 查询目标后逐项导航、操作并复查 |
| 多路点巡航 | ⚪ | 顺序调用 `navigate`，逐段保留最后确认位置 |
| 批量浇水 | 🧩 | 单次可执行 Skill 在显式矩形范围内规划安全站位与蓄力，逐项浇水并返回部分进度 |
| 批量收获 | 🧩 | 单次可执行 Skill 按公开收获方式执行手摘或镰刀动作，并复查世界与背包变化 |
| 查找水源并装满喷壶 | 🧩 | 单次可执行 Skill 扫描当前地图并按当前玩家原生寻路碰撞事实计算 BFS 可达成本，选择最近岸边站位后复查水量 |
| 单格种植 | ⚪ | 选择种子与空耕地，装备、交互并复查作物和背包 |
| 回家睡觉 | 🧩 | 单次可执行 Skill 连续查询住宅与床位、正常导航、确认睡眠，并以换日后菜单清空和玩家可操作收口 |
| 购物流程 | ⚪ | 查询商店、选择商品、购买并复查金币与背包 |

上述农业与睡眠工作流都在 `skill/examples/` 提供 Agent Skill 示例；浇水、收获、喷壶补水与睡眠同时带有可执行脚本，由 MCP 复用当前 Owner Session 运行，其余示例仍是 Agent 指引。它们都不会注册成新的 Mod 复合能力。

新增或调整能力时，先更新 `spec/` 和实现，再同步本页状态。
