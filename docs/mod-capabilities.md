# Mod 能力清单

当前公开 V1 已实现 **20 项能力**：5 项只读观察能力、15 项游戏操作能力。

本页只展示实现状态，不重复定义协议。详细行为见 [`spec/capabilities/behavior.md`](../spec/capabilities/behavior.md)，权威能力集合见 [`spec/capabilities/manifest.yaml`](../spec/capabilities/manifest.yaml)。

状态说明：✅ 已实现并注册；🟡 已列入后续候选；⚪ 由 Agent/Skill 编排，不计划增加 Mod 复合命令。

## 已实现

| 类型 | 能力 | 状态 | 功能 |
|---|---|---:|---|
| 观察 | `query_runtime` | ✅ | 查询日期、时间、天气、玩家位置、资源与 UI 摘要 |
| 观察 | `query_world` | ✅ | 查询区域内地块、对象、门、Warp、角色与动物 |
| 观察 | `query_inventory` | ✅ | 查询玩家背包或已解析容器的槽位与物品 |
| 观察 | `query_ui` | ✅ | 查询菜单、对话、商店、箱子、背包、装备槽与制作配方 |
| 观察 | `inspect` | ✅ | 批量解析查询产生的不透明 Ref |
| 基础动作 | `say` | ✅ | 在游戏聊天中发送文本 |
| 基础动作 | `emote` | ✅ | 播放受支持的玩家表情 |
| 基础动作 | `face` | ✅ | 调整玩家朝向 |
| 移动与交互 | `navigate` | ✅ | 同地图或跨地图导航到位置、对象或角色附近 |
| 移动与交互 | `interact` | ✅ | 与相邻位置、对象或角色执行原生交互 |
| 移动与交互 | `use_tool` | ✅ | 对相邻目标使用当前工具，支持蓄力等级 |
| 背包与装备 | `equip` | ✅ | 切换当前背包工具栏物品 |
| 背包与装备 | `transfer_inventory_item` | ✅ | 在受支持箱子菜单中双向转移指定数量物品 |
| 背包与装备 | `set_equipment_slot` | ✅ | 穿戴、替换或取下装备 |
| 背包与装备 | `move_inventory_item` | ✅ | 整件移动背包物品或交换槽位 |
| 菜单 | `open_menu` | ✅ | 打开受支持的顶层游戏菜单 |
| 菜单 | `activate_ui` | ✅ | 激活查询返回的受支持语义 UI 元素 |
| 菜单 | `close_menu` | ✅ | 安全关闭当前菜单 |
| 制作与交易 | `craft_item` | ✅ | 使用当前制作页的配方 Ref 执行有界批量制作 |
| 制作与交易 | `purchase_shop_item` | ✅ | 使用当前商店商品 Ref 执行有界金币购买 |

## Agent/Skill 编排

下列目标由现有原子能力组合完成，不计划在 Mod 中增加批处理或复合 Handler：

| 工作流 | 状态 | 组合方式 |
|---|---:|---|
| 重复使用工具直到目标消失 | ⚪ | `query_world → use_tool → query_world` 有界循环 |
| 抚摸动物、拾取掉落物、区域采矿 | ⚪ | 查询目标后逐项导航、操作并复查 |
| 多路点巡航 | ⚪ | 顺序调用 `navigate`，逐段保留最后确认位置 |
| 批量浇水 | ⚪ | 查询含水状态后逐格导航、用工具并复查 |
| 购物流程 | ⚪ | 查询商店、选择商品、购买并复查金币与背包 |

新增或调整能力时，先更新 `spec/` 和实现，再同步本页状态。
