# ADR-0001：公开 V1 的能力边界与版本历史

- 状态：已接受
- 日期：2026-07-26

## 背景

旧实现的 Protocol `2.4.5` 同时包含公开能力、未公开分支、V2 类型复用和私有平台上下文。直接把它发布为开源协议会制造不存在的历史兼容承诺，并迫使新实现继续解释旧命名和重复概念。

## 决策

1. 公开协议建立独立的 V1 版本历史，protobuf package 使用 `stardew_valley.mcp.v1`。
2. Protocol `2.4.5` 仅作为行为证据，不属于公开 V1 的兼容前身。
3. V1 公开 15 项能力；原 18 项候选的逐项裁决见 `../capabilities/decisions.md`。
4. V1 只有 Proto 业务协议，不提供 V2 JSON、Legacy Handler、旧文件桥或私有 Hosted Profile。
5. 仓库在实现完成前保持 `0.x` 产品版本；公开契约的 `contract_version` 从 `1.0.0` 开始。

## 后果

- 新 Mod 与新 MCP 必须成对升级，不能和旧 `2.4.5` 实现互连。
- 可以删除内部遗留字段和未公开能力，不需要为尚未公开的消费者提供迁移 Adapter。
- 旧实现中有价值的算法仍可在通过依赖审计后重写，但不得带入旧命名空间或运行时类型。
