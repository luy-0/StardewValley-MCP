# 有界浇灌指定范围作物

## 可用工具

以下是脚本获得的最小原子 Tool 权限，不是要求 Agent 逐项编排的步骤：

- `stardew_query_runtime`：检查天气、时间、位置和体力。
- `stardew_query_inventory`：寻找喷壶并读取余水、容量与 Item Ref。
- `stardew_query_world`：枚举查询范围内作物、站位地块、对象与角色。
- `stardew_inspect`：每次动作前后复查目标 Crop Ref。
- `stardew_navigate`：走到脚本选定的安全站位并朝向目标。
- `stardew_equip`：明确装备本轮喷壶。
- `stardew_use_tool`：对锁定作物执行一次零蓄力或安全蓄力喷壶动作。

## 工作流程

1. Agent 先用只读查询确定当前地图内要处理的矩形 `area`；范围最大 32×32，不能把未查询区域称为已经处理。
2. Agent 只调用一次派生浇水 Tool，并传入 `area`。可选参数用于限制目标数、动作数、期限、最低体力、停止时间与最大蓄力等级；没有明确需求时使用 Schema 默认值。
3. 脚本在同一个 Owner Session 内完成预检、喷壶选择、完整范围查询、站位规划、导航、动作与逐格后置复查。蓄力只有在完整影响范围都是本轮未浇水作物、站位安全且水量充足时才会使用，否则自动降为单格。
4. Agent 根据 `finalStatus`、`stopReason`、`remainingTargets` 与 `resumeHint` 汇报结果。只有返回 `resumable=true` 时，才可以在解决停止原因后由用户决定是否重新调用。

## 停止条件

- 达到目标／动作／期限上限、体力或时间门槛、喷壶为空、导航受阻、目标变化、无安全站位或无进展时有界停止。
- 日期变化后不再查询新一天的目标；取消发生在变更调用中或最后动作后置条件不可确认时返回 `unknown`。
- 任一 `unknown` 终态禁止自动重放最后动作；脚本不会自动寻找水源或跨地图补水。

## 输出要求

返回查询范围、初始与本轮计划目标数、确认浇水／跳过／失败数、动作与蓄力次数、喷壶和体力变化、最后位置、停止原因以及剩余目标。逐格未观察到 `watered=true` 的目标不得计入完成。

## 安全边界

本 Skill 会消耗游戏时间、体力和喷壶水量，需要 `--allow-write`。它只在玩家当前地图和显式矩形范围内工作，不锄地、不种植、不吃食物、不传送、不自动补水，也不把范围外作物纳入完成结论。
